# 安全性与权限管理

数据库安全是 Web 安全的核心。作为前端开发者，你可能习惯直接用 `root` 连所有库，这在生产环境是极度危险的。本章教你如何按规范管理 MySQL 安全。

## 1. 用户管理

**永远不要在应用程序代码中使用 `root` 账户**。root 拥有一切权限，一旦泄露，黑客可以直接删库跑路。

### 创建用户
MySQL 的用户由 `用户名` + `主机` 组成。

```sql
-- 创建一个只能从本机登录的用户
CREATE USER 'app_user'@'localhost' IDENTIFIED BY 'StrongPassword!123';

-- 创建一个可以从任意 IP 登录的用户（通常用于云数据库，但最好限制具体网段）
CREATE USER 'remote_user'@'%' IDENTIFIED BY 'StrongPassword!123';

-- 修改密码 (MySQL 8.0+)
ALTER USER 'app_user'@'localhost' IDENTIFIED BY 'NewPassword!456';
```

## 2. 权限控制 (GRANT)

遵循 **最小权限原则 (Principle of Least Privilege)**：只给用户刚好够用的权限。

```sql
-- 授予 my_blog 库所有表的增删改查权限（适合普通业务代码）
GRANT SELECT, INSERT, UPDATE, DELETE ON my_blog.* TO 'app_user'@'localhost';

-- 如果代码需要改表结构（如运行 migration），需要给 ALTER/CREATE
GRANT ALTER, CREATE, DROP ON my_blog.* TO 'deploy_user'@'localhost';

-- 刷新权限（通常自动生效，但手动刷一下是个好习惯）
FLUSH PRIVILEGES;

-- 查看某个用户的权限
SHOW GRANTS FOR 'app_user'@'localhost';
```

**撤销权限**：
```sql
REVOKE DELETE ON my_blog.* FROM 'app_user'@'localhost';
```

## 3. SQL 注入 (SQL Injection)

这是最著名、最古老也是最危险的 Web 漏洞。

### 漏洞原理
假设你的 Node.js 代码这样写：

```javascript
/* ❌ 错误写法：直接拼接字符串 */
const sql = "SELECT * FROM users WHERE username = '" + userInput + "'";
```

如果恶意用户输入 `userInput` 为：`' OR '1'='1`。
SQL 就变成了：
```sql
SELECT * FROM users WHERE username = '' OR '1'='1';
```
`'1'='1'` 永远为真，OR 也是真。结果：**黑客不需要密码就登录了任意账号，或者导出了所有数据**。

### 防御手段：参数化查询 (Prepared Statements)

**原理**：先发给数据库一个带占位符 `?` 的模板，数据库编译它。然后再把参数传过去。数据库会把参数严格当纯文本处理，绝不会把参数当命令执行。

```javascript
/* ✅ 正确写法：使用占位符 */
const sql = 'SELECT * FROM users WHERE username = ?';
// 库会自动处理转义
connection.execute(sql, [userInput]);
```

无论你用 Java, PHP, Go 还是 Node.js，**只要用了 `execute` 或 `prepare` 并传数组参数，你就 100% 安全了**。千万别在 JS 层自己搞正则去过滤（很容易被绕过）。

## 4. 传输加密 (SSL/TLS)

默认情况下，MySQL 的流量是明文的。如果应用服务器和数据库不在同一个内网（比如你连公网 RDS），中间人可以截获数据。

- **开启 SSL**：现在的云数据库默认都开启。
- **客户端配置**：连接时指定证书。

```javascript
// Node.js mysql2 开启 SSL
const connection = await mysql.createConnection({
  // ...
  ssl: {
    rejectUnauthorized: true,
    ca: fs.readFileSync('./ca-cert.pem') // 云厂商提供的证书
  }
});
```
