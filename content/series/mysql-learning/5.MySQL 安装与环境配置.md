# MySQL 安装与环境配置

在开始敲 SQL 代码之前，我们需要先在本地把 MySQL 跑起来。对于前端开发者来说，配置后端环境往往是最头疼的一步。别担心，本文提供了多种安装方式，其中 **Docker 安装** 是最为推荐的，因为它干净、可逆且不污染本机环境。

## 方式一：使用 Docker 安装（强烈推荐 🐳）

如果你已经安装了 Docker，这是最快、最现代的方式。它能让你在几秒钟内启动一个干净的 MySQL 实例。

### 1. 拉取镜像
这里我们使用 MySQL 8.0 版本（目前最主流的稳定版）。

```bash
docker pull mysql:8.0
```

### 2. 启动容器
运行以下命令启动一个 MySQL 实例：

```bash
# 命令解释：
# --name mysql-dev: 给容器起个名字叫 mysql-dev
# -p 3306:3306: 把容器内的 3306 端口映射到本机的 3306 端口
# -e MYSQL_ROOT_PASSWORD=root: 设置 root 用户的密码为 "root"（开发环境简单点）
# -d: 后台运行
docker run --name mysql-dev -p 3306:3306 -e MYSQL_ROOT_PASSWORD=root -d mysql:8.0
```

### 3. 验证安装
查看容器是否在运行：

```bash
docker ps
# 应该能看到 mysql:8.0 正在运行
```

进入容器内部使用命令行：

```bash
docker exec -it mysql-dev mysql -u root -p
# 输入密码: root
# 成功进入后会看到 mysql> 提示符
```

## 方式二：macOS 本地安装 (使用 Homebrew)

如果你是 Mac 用户且不想用 Docker，Homebrew 是最佳选择。

### 1. 安装
```bash
brew install mysql
```

### 2. 启动服务
```bash
brew services start mysql
```

### 3. 初始化安全配置
这是非常重要的一步，用于设置 root 密码和移除不安全的默认设置。

```bash
mysql_secure_installation
```
按照提示：
- 设置密码验证组件？（开发环境选 No 即可，生产环境选 Yes）
- 设置 root 密码？（输入你想设置的密码）
- 移除匿名用户？（Choose Yes）
- 禁止 root 远程登录？（开发环境选 No，方便 GUI 连接；生产环境 Yes）
- 移除测试数据库？（Choose Yes）
- 重新加载权限表？（Choose Yes）

### 4. 登录
```bash
mysql -u root -p
```

## 方式三：Windows 安装

Windows 用户建议直接下载官方安装器（MySQL Installer）。

1. 访问 [MySQL Downloads](https://dev.mysql.com/downloads/installer/)。
2. 下载 **MySQL Installer Community**。
3. 运行安装程序，选择 **"Developer Default"**（开发者默认），它会安装 MySQL Server、MySQL Workbench（图形管理工具）等。
4. 在配置向导中：
   - Config Type 选 "Development Computer"。
   - Port 保持 3306。
   - Authentication Method 选 "Use Legacy Authentication Method"（为了兼容旧的 Node.js 驱动，特别是 MySQL 5.x 时代的项目；新项目选 Strong Password Encryption 也行，现在的驱动都支持了）。
   - 设置 root 密码。

## 关键配置文件

无论哪种安装方式，了解 MySQL 的配置文件位置都很重要。通常该文件名为 `my.cnf` (Linux/macOS) 或 `my.ini` (Windows)。

**常见位置**：
- Linux: `/etc/my.cnf`
- macOS (Homebrew): `/usr/local/etc/my.cnf` (Intel) 或 `/opt/homebrew/etc/my.cnf` (M1/M2)

**常见配置项**：

```ini
[mysqld]
# 端口号，默认 3306
port = 3306

# 数据存储目录
datadir = /var/lib/mysql

# 允许最大连接数（开发环境不用改，生产环境可能要调大）
max_connections = 151

# 字符集设置（非常重要！防止中文乱码）
# MySQL 8.0 默认就是 utf8mb4，通常不需要改
# 老版本必须配置
character-set-server = utf8mb4
collation-server = utf8mb4_unicode_ci

[client]
default-character-set = utf8mb4
```

## GUI 工具推荐

虽然我们学习时会用命令行，但在实际开发中，图形化界面（GUI）能极大提高效率。

1. **MySQL Workbench**（官方，免费）：功能最全，但有点重，界面略显过时。
2. **DBeaver**（社区版免费）：**强烈推荐**。基于 Java，支持所有主流数据库，功能强大，界面现代。
3. **TablePlus**（Mac 主要是收费）：界面极美，体验极佳，免费版有窗口限制。
4. **Navicat**（收费）：老牌王者，功能非常强，但价格较贵。
5. **VS Code 插件**：
   - **MySQL** (Jun Han)：可以直接在 VS Code 里连接数据库，对不想切窗口的开发者很友好。

## 验证你的环境

让我们做最后一步检查，确保一切就绪。

1. 打开你选择的 GUI 工具（或命令行）。
2. 创建一个新的连接：
   - Host: `localhost` (或 `127.0.0.1`)
   - Port: `3306`
   - User: `root`
   - Password: `root` (你刚才设置的)
3. 连接成功后，运行下面这条 SQL：

```sql
SELECT VERSION(), NOW();
```

如果这就返回了版本号（如 `8.0.35`）和当前时间，恭喜你！🎉 你的 MySQL 开发环境已经准备就绪。

### 常见问题 Troubleshooting

- **连接被拒绝 (Connection Refused)**：检查 MySQL 服务是否启动了。MAC 用 `brew services list` 看状态，Docker 用 `docker ps`。
- **认证错误 (Authentication protocol)**：如果 Node.js 连接报错 `ER_NOT_SUPPORTED_AUTH_MODE`，说明你的驱动太老不支持 MySQL 8 的新加密方式。
  - 解决办法：升级 Node.js 驱动，或者运行 SQL 修改密码加密方式：
    ```sql
    ALTER USER 'root'@'%' IDENTIFIED WITH mysql_native_password BY 'password';
    ```
- **中文乱码**：检查 `SHOW VARIABLES LIKE 'char%';`，确保 `character_set_server` 是 `utf8mb4`。
