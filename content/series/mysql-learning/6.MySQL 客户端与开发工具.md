# MySQL 客户端与开发工具

工欲善其事，必先利其器。有了运行中的 MySQL 服务端，我们需要合适的工具来连接和操作它。本章通过前端开发者的视角，介绍从原生命令行到现代 GUI，再到代码集成的各种"连接方式"。

## 1. 命令行客户端 (CLI)

不管 GUI 多好用，**命令行永远是最后的防线**。当你 SSH 连到服务器排查故障时，通常只有命令行可用。

### 基础连接
```bash
# -h: 主机 (host)，默认 localhost
# -P: 端口 (port)，默认 3306
# -u: 用户 (user)
# -p: 密码 (password)，注意 -p 后面不要直接跟密码（不安全），回车后再输
mysql -h 127.0.0.1 -P 3306 -u root -p
```

### 常用命令操作
进入 `mysql>` 提示符后，常用的管理命令：

```sql
-- 显示所有数据库
SHOW DATABASES;

-- 切换当前数据库（类似 cd）
USE my_database;

-- 显示当前库的所有表（类似 ls）
SHOW TABLES;

-- 查看表结构（非常常用！）
DESCRIBE users; 
-- 或者简写
DESC users;

-- 查看建表语句（查看详细约束和字符集时很有用）
SHOW CREATE TABLE users;

-- 退出
EXIT; -- 或者 \q
```

**小技巧**：在 MySQL 命令行里，命令必须以分号 `;` 或 `\G` 结尾。`\G` 会将结果垂直显示，看大段数据时特别方便。

## 2. 图形化界面工具 (GUI)

对于复杂的查询和表结构设计，GUI 工具效率更高。

### MySQL Workbench (官方)
- **定位**：官方旗舰，功能最全。
- **优点**：自带可视化的的数据库建模工具（E-R 图），可以直接从图生成 SQL，或从数据库逆向生成图。
- **缺点**：界面比较传统，启动慢，偶尔崩溃。

### DBeaver (社区首选)
- **定位**：通用的数据库管理工具。
- **优点**：支持所有数据库（MySQL, PG, Redis...），Eclipse 风格，功能极其强大，查看数据的 Grid 视图体验很好。
- **推荐**：前端开发者如果只想装一个工具，就装这个。

### TablePlus / Sequel Ace (macOS)
- **定位**：原生、轻量、高颜值。
- **优点**：启动极快，界面符合原生 macOS 设计，多标签页管理极其流畅。
- **缺点**：TablePlus 免费版有窗口限制。

## 3. 在 VS Code 中使用

作为前端开发者，能不离开 VS Code 当然最好。

- **MySQL (Jun Han)**：最流行的插件，可以在侧边栏浏览数据库，右键运行 SQL。
- **SQLTools**：更通用的数据库管理插件，支持格式化 SQL，自动补全。

## 4. 编程语言连接：Node.js 驱动

这是前端工程师最关心的部分——如何在代码里连接 MySQL。主要有两种流派：**驱动层** 和 **ORM 层**。

### 方式 A：原生驱动 `mysql2` (推荐入门)
`mysql2` 是目前 Node.js 社区最流行的 MySQL 驱动，比老牌的 `mysql` 库更快，且支持 Promise。

**安装**：
```bash
npm install mysql2
```

**代码示例**：
```javascript
// db.js
const mysql = require('mysql2/promise');

// 创建连接池（推荐用连接池而不是单个连接）
const pool = mysql.createPool({
  host: 'localhost',
  user: 'root',
  password: 'password',
  database: 'test_db',
  waitForConnections: true,
  connectionLimit: 10,
  queueLimit: 0
});

async function main() {
  try {
    // 简单的查询
    // execute 比 query 更安全，会自动预编译 SQL，防止注入
    const [rows, fields] = await pool.execute(
      'SELECT * FROM users WHERE id > ? AND status = ?',
      [10, 'active'] 
    );
    
    console.log(rows); // 打印结果数组
  } catch (err) {
    console.error(err);
  }
}

main();
```

### 方式 B：Query Builder (Knex.js)
介于原生 SQL 和 ORM 之间。它让你用 JS 方法写 SQL，但不管模型关系。

```javascript
/* Knex 写法 */
knex('users')
  .where('id', '>', 10)
  .andWhere('status', 'active')
  .select('*')
```
**优点**：不需要手写字符串 SQL，跨数据库兼容。

### 方式 C：ORM (Prisma / TypeORM / Sequelize)
对象关系映射。把数据库表映射成 JS 类/对象。

**Prisma 示例（现代前端首选）**：
```typescript
/* prisma.schema 定义 */
model User {
  id    Int     @id @default(autoincrement())
  email String  @unique
  name  String?
}

/* TS 代码 */
const users = await prisma.user.findMany({
  where: {
    id: { gt: 10 },
    status: 'active'
  }
})
```
**优点**：全自动类型提示（TypeScript 神器），开发速度极快。
**缺点**：屏蔽了底层细节，复杂查询可能性能不佳。

## 建议

- **初学者**：先用命令行 `mysql` 练手，熟悉基础命令。
- **写作业/调试**：用 **DBeaver** 或 **TablePlus**。
- **写后端代码**：
  - 如果项目小且想学 SQL：用 `mysql2`。
  - 如果是全栈 TypeScript 项目：强烈推荐 **Prisma**。
