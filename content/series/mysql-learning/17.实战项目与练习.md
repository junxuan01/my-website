# 实战项目与练习

恭喜你读到了最后一章！最好的学习方式就是动手。这里有三个不同难度的实战任务，建议你花个周末挑战一下。

## 练习 1：设计博客数据库 (DB Design)

**目标**：设计一个功能完整的博客系统的 Schema。

**需求**：
1. 用户 (User)：ID、昵称、邮箱、密码、头像。
2. 文章 (Post)：标题、内容、发布时间、阅读量。
3. 评论 (Comment)：内容、时间、层级（回复的回复）。
4. 标签 (Tag)：文章和标签是多对多关系。

**要求**：
- 画出 E-R 图。
- 写出完整的 `CREATE TABLE` 语句。
- 考虑索引：我要按"阅读量"倒序分页显示文章；我要查"某个标签下"的所有文章。

## 练习 2：复杂 SQL 挑战 (SQL Query)

**准备**：
你需要去下载一个测试数据集（比如 MySQL 官方的 **Sakila** 示例数据库，都是存电影租赁信息的）。

**任务**：
1. 找出租赁次数最多的前 10 部电影。
2. 找出总消费最高的客户，并列出他看过的所有电影名称。
3. 找出所有"恐怖片"类别的电影平均时长。
4. （高难度）连续 3 天都有租赁记录的用户。

## 练习 3：全栈 CRUD (Coding)

**目标**：用 Node.js + MySQL 完成一个 "Todo List" 接口。

**技术栈**：Express/Koa, mysql2

**API 列表**：
- `POST /todos`：创建任务（支持 JSON 也就是要用 JSON 字段存 sub-tasks）。
- `GET /todos?status=done`：获取已完成任务。
- `PATCH /todos/:id`：修改状态。
- `DELETE /todos/:id`：软删除。

**进阶要求**：
- 实现分页。
- 加上简单的 JWT 登录验证，任务是私有的（只能查自己的）。

## 结语

MySQL 的世界浩瀚无垠，我们这 17 篇文章只是带你推开了门。

- 如果你想往**高并发架构**走，去研究：分库分表、MyCAT、ShardingSphere。
- 如果你想往**DBA/运维**走，去研究：主从复制原理、MGR、PXC、灾备。
- 如果你想往**全栈专家**走，去研究：Schema 设计范式、SQL 调优、Redis/ES 与 MySQL 的配合。

保持好奇心，多看 `EXPLAIN`，多看错误日志。祝你在数据库的海洋里乘风破浪！🌊
