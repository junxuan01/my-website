# 第 2 课：你的第一个 SQL 查询

> 停止阅读理论，打开终端，让我们写代码！

## 开始之前

假设你已经安装了 MySQL（如果还没有，用 Docker 快速启动：`docker run --name mysql -e MYSQL_ROOT_PASSWORD=password -p 3306:3306 -d mysql:latest`）。

连接到 MySQL：

```bash
mysql -u root -p
# 输入密码: password
```

看到 `mysql>` 提示符？很好，让我们开始！

## 场景：构建一个"待办事项"应用

我们要创建一个简单的待办应用，需要存储：
- 任务标题
- 是否完成
- 创建时间

## 第 1 步：创建数据库

```sql
-- 创建一个数据库（就像创建一个文件夹）
CREATE DATABASE todoapp;

-- 使用这个数据库
USE todoapp;
```

**输出**：
```
Query OK, 1 row affected (0.01 sec)
Database changed
```

**前端类比**：
```javascript
// 类似于
const todoapp = {};
```

## 第 2 步：创建表

```sql
CREATE TABLE todos (
  id INT PRIMARY KEY AUTO_INCREMENT,
  title VARCHAR(200) NOT NULL,
  done BOOLEAN DEFAULT false,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

**逐行解释**：

```sql
id INT PRIMARY KEY AUTO_INCREMENT
```
- `id`：字段名
- `INT`：整数类型
- `PRIMARY KEY`：主键，每条记录的唯一标识
- `AUTO_INCREMENT`：自动递增（1, 2, 3...），不用手动填

```sql
title VARCHAR(200) NOT NULL
```
- `VARCHAR(200)`：可变长度字符串，最多 200 个字符
- `NOT NULL`：不能为空

```sql
done BOOLEAN DEFAULT false
```
- `BOOLEAN`：布尔值（其实是 `TINYINT(1)`）
- `DEFAULT false`：默认值为 false

```sql
created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
```
- `TIMESTAMP`：时间戳
- `DEFAULT CURRENT_TIMESTAMP`：自动设置为当前时间

**前端类比**：
```javascript
class Todo {
  constructor(title) {
    this.id = generateId();           // AUTO_INCREMENT
    this.title = title;                 // VARCHAR(200)
    this.done = false;                  // BOOLEAN DEFAULT false
    this.created_at = new Date();       // TIMESTAMP
  }
}
```

## 第 3 步：插入数据（CREATE）

```sql
INSERT INTO todos (title) VALUES ('学习 SQL');
```

**输出**：
```
Query OK, 1 row affected (0.01 sec)
```

再插入几条：

```sql
INSERT INTO todos (title, done) VALUES 
('买牛奶', false),
('写文档', true),
('健身', false);
```

**前端类比**：
```javascript
todos.push({ id: 1, title: '学习 SQL', done: false, created_at: new Date() });
todos.push({ id: 2, title: '买牛奶', done: false, created_at: new Date() });
```

## 第 4 步：查询数据（READ）

### 查询所有数据

```sql
SELECT * FROM todos;
```

**输出**：
```
+----+-----------+------+---------------------+
| id | title     | done | created_at          |
+----+-----------+------+---------------------+
|  1 | 学习 SQL  |    0 | 2026-01-15 10:30:00 |
|  2 | 买牛奶    |    0 | 2026-01-15 10:31:00 |
|  3 | 写文档    |    1 | 2026-01-15 10:31:00 |
|  4 | 健身      |    0 | 2026-01-15 10:31:00 |
+----+-----------+------+---------------------+
```

### 只查询特定列

```sql
SELECT title, done FROM todos;
```

**前端类比**：
```javascript
todos.map(t => ({ title: t.title, done: t.done }))
```

### 过滤数据（WHERE）

查询未完成的任务：

```sql
SELECT * FROM todos WHERE done = false;
```

或简写：

```sql
SELECT * FROM todos WHERE done = 0;
```

**前端类比**：
```javascript
todos.filter(t => t.done === false)
```

### 排序（ORDER BY）

按创建时间倒序：

```sql
SELECT * FROM todos ORDER BY created_at DESC;
```

**前端类比**：
```javascript
todos.sort((a, b) => b.created_at - a.created_at)
```

### 限制数量（LIMIT）

只显示前 2 条：

```sql
SELECT * FROM todos LIMIT 2;
```

**前端类比**：
```javascript
todos.slice(0, 2)
```

## 第 5 步：更新数据（UPDATE）

标记任务 1 为已完成：

```sql
UPDATE todos SET done = true WHERE id = 1;
```

**⚠️ 重要**：永远记得加 `WHERE`！否则会更新所有行！

**前端类比**：
```javascript
const todo = todos.find(t => t.id === 1);
todo.done = true;
```

验证：

```sql
SELECT * FROM todos WHERE id = 1;
```

**输出**：
```
+----+-----------+------+---------------------+
| id | title     | done | created_at          |
+----+-----------+------+---------------------+
|  1 | 学习 SQL  |    1 | 2026-01-15 10:30:00 |
+----+-----------+------+---------------------+
```

## 第 6 步：删除数据（DELETE）

删除任务 2：

```sql
DELETE FROM todos WHERE id = 2;
```

**⚠️ 重要**：再次强调，记得加 `WHERE`！

**前端类比**：
```javascript
const index = todos.findIndex(t => t.id === 2);
todos.splice(index, 1);
```

验证：

```sql
SELECT * FROM todos;
```

任务 2 不见了！

## 实战练习：用户表

现在独立创建一个 `users` 表：

**需求**：
- ID（自增主键）
- 用户名（最多 50 字符，不能重复）
- 邮箱（最多 100 字符）
- 年龄（整数）
- 创建时间（自动）

<details>
<summary>🤔 先自己试试，再看答案</summary>

```sql
CREATE TABLE users (
  id INT PRIMARY KEY AUTO_INCREMENT,
  username VARCHAR(50) NOT NULL UNIQUE,
  email VARCHAR(100),
  age INT,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 插入测试数据
INSERT INTO users (username, email, age) VALUES
('alice', 'alice@example.com', 25),
('bob', 'bob@example.com', 30),
('charlie', 'charlie@example.com', 22);

-- 查询年龄 >= 25 的用户
SELECT * FROM users WHERE age >= 25;

-- 更新 alice 的年龄
UPDATE users SET age = 26 WHERE username = 'alice';

-- 删除 charlie
DELETE FROM users WHERE username = 'charlie';
```

</details>

## 常用数据类型速查

| 类型 | 说明 | 示例 | 前端类型 |
|------|------|------|----------|
| `INT` | 整数（-21亿 到 21亿） | `age INT` | `number` |
| `BIGINT` | 大整数 | `user_id BIGINT` | `BigInt` |
| `VARCHAR(n)` | 可变字符串 | `name VARCHAR(50)` | `string` |
| `TEXT` | 长文本 | `content TEXT` | `string` |
| `BOOLEAN` | 布尔值 | `is_active BOOLEAN` | `boolean` |
| `DATE` | 日期 | `birth_date DATE` | `Date` |
| `TIMESTAMP` | 时间戳 | `created_at TIMESTAMP` | `Date` |
| `DECIMAL(M,D)` | 精确小数（金额） | `price DECIMAL(10,2)` | `string` |
| `JSON` | JSON 数据 | `settings JSON` | `object` |

## SQL vs JavaScript 对照表

| 操作 | SQL | JavaScript |
|------|-----|------------|
| 添加 | `INSERT INTO todos VALUES (...)` | `todos.push(...)` |
| 查询全部 | `SELECT * FROM todos` | `todos` |
| 过滤 | `SELECT * FROM todos WHERE done = false` | `todos.filter(t => !t.done)` |
| 排序 | `SELECT * FROM todos ORDER BY id DESC` | `todos.sort((a,b) => b.id - a.id)` |
| 限制数量 | `SELECT * FROM todos LIMIT 5` | `todos.slice(0, 5)` |
| 更新 | `UPDATE todos SET done = true WHERE id = 1` | `todos.find(t => t.id === 1).done = true` |
| 删除 | `DELETE FROM todos WHERE id = 1` | `todos = todos.filter(t => t.id !== 1)` |
| 计数 | `SELECT COUNT(*) FROM todos` | `todos.length` |

## 关键概念总结

### DDL（数据定义语言）

```sql
CREATE DATABASE mydb;    -- 创建数据库
USE mydb;                -- 使用数据库
CREATE TABLE users (...);-- 创建表
DROP TABLE users;        -- 删除表
```

### DML（数据操作语言）

```sql
INSERT INTO ...  -- 增
SELECT * FROM    -- 查
UPDATE ... SET   -- 改
DELETE FROM ...  -- 删
```

### WHERE 条件

```sql
WHERE age = 18           -- 等于
WHERE age != 18          -- 不等于
WHERE age > 18           -- 大于
WHERE age >= 18          -- 大于等于
WHERE age BETWEEN 18 AND 30  -- 范围
WHERE name LIKE '%alice%'     -- 模糊匹配
WHERE email IS NULL      -- 为空
WHERE email IS NOT NULL  -- 不为空
WHERE age IN (18, 20, 22)  -- 在列表中
```

## 常见错误和解决方案

### 错误 1：忘记 WHERE 子句

```sql
-- 😱 这会更新所有行！
UPDATE users SET age = 18;

-- ✅ 正确的做法
UPDATE users SET age = 18 WHERE id = 1;
```

**最佳实践**：先用 SELECT 验证：

```sql
-- 1. 先查看会影响哪些行
SELECT * FROM users WHERE id = 1;

-- 2. 确认无误后再执行 UPDATE
UPDATE users SET age = 18 WHERE id = 1;
```

### 错误 2：字符串没加引号

```sql
-- ❌ 错误
SELECT * FROM users WHERE username = alice;

-- ✅ 正确
SELECT * FROM users WHERE username = 'alice';
```

### 错误 3：LIMIT 语法混淆

```sql
-- 获取第 11-20 条记录

-- ❌ 错误理解
SELECT * FROM users LIMIT 11, 20;  -- 这是从第11条开始取20条

-- ✅ 正确
SELECT * FROM users LIMIT 10, 10;  -- offset 10, 取10条
-- 或者
SELECT * FROM users LIMIT 10 OFFSET 10;  -- 更清晰的语法
```

## 小贴士

### 1. 使用 `IF NOT EXISTS`

```sql
CREATE DATABASE IF NOT EXISTS todoapp;
CREATE TABLE IF NOT EXISTS users (...);
```

这样即使数据库/表已存在也不会报错。

### 2. 使用 `DEFAULT` 值

```sql
created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
status ENUM('active', 'inactive') DEFAULT 'active'
```

减少手动输入，避免遗漏。

### 3. 字符集设置

```sql
CREATE DATABASE mydb 
CHARACTER SET utf8mb4 
COLLATE utf8mb4_unicode_ci;
```

`utf8mb4` 支持 emoji 和所有 Unicode 字符。

### 4. 注释你的表

```sql
CREATE TABLE users (
  id INT PRIMARY KEY AUTO_INCREMENT COMMENT '用户ID',
  username VARCHAR(50) NOT NULL COMMENT '用户名'
) COMMENT='用户表';
```

### 5. 使用事务保护重要操作

```sql
START TRANSACTION;

UPDATE accounts SET balance = balance - 100 WHERE id = 1;
UPDATE accounts SET balance = balance + 100 WHERE id = 2;

-- 检查无误后提交
COMMIT;

-- 如果出错，可以回滚
-- ROLLBACK;
```

## 补充：修改表结构（ALTER TABLE）

项目上线后，经常需要修改表结构：

### 添加字段

```sql
-- 给 users 表添加 avatar 字段
ALTER TABLE users ADD COLUMN avatar VARCHAR(200);

-- 添加字段并指定位置
ALTER TABLE users ADD COLUMN nickname VARCHAR(50) AFTER username;
```

### 修改字段

```sql
-- 修改字段类型
ALTER TABLE users MODIFY COLUMN avatar VARCHAR(500);

-- 重命名字段
ALTER TABLE users CHANGE COLUMN avatar avatar_url VARCHAR(500);
```

### 删除字段

```sql
-- 删除字段（谨慎操作！）
ALTER TABLE users DROP COLUMN avatar_url;
```

### 添加索引

```sql
-- 添加普通索引
ALTER TABLE users ADD INDEX idx_email (email);

-- 添加唯一索引
ALTER TABLE users ADD UNIQUE INDEX idx_username (username);
```

## 补充：去重查询（DISTINCT）

查询不重复的值：

```sql
-- 查询所有不同的作者 ID
SELECT DISTINCT author_id FROM posts;

-- 查询有多少个不同的作者
SELECT COUNT(DISTINCT author_id) FROM posts;

-- 多列去重
SELECT DISTINCT author_id, status FROM posts;
```

**前端类比**：

```javascript
// DISTINCT = [...new Set()]
const authorIds = [...new Set(posts.map(p => p.author_id))];
```
